Verschlüsselung

Nachrichten werden auf deinem Handy verschlüsselt; der Server-Betreiber kann sie nicht lesen. Sichtbar für ihn bleibt nur, wer wann mit wem schreibt. Vergleicht eure Sicherheitsnummern einmal persönlich – stimmen sie, liest niemand dazwischen mit.
