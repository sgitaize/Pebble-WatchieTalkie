1.5: Pause phone notifications (ntfy/Telegram/Pushover) from the watch: hold SELECT in the chat list or a chat → "Pause push" (duration set in the settings). New setting: no further notification within X minutes after one. The radio beep switch moved into the same menu (hold SELECT in the chat list). New in the settings under "Display on the watch": text size (small, large bold, extra large bold), background and text color with presets and a live preview, and "keep the backlight on while the app is open". Better default look: black text on white, your own messages in light gray instead of pink. Fix: the selection in the chat list no longer jumps to the top when the list refreshes.
1.4: Emoji picker (hold SELECT in a chat → Emoji …) – sends real emoji, shown as text smileys on the watch. Delete your last message in a chat (hold SELECT → Delete my last message) – it disappears for everyone. Group owners can remove members in the settings. If the server is down or busy, the watch now shows an error and retries automatically instead of staying on "Loading".
1.3: Hold SELECT in the chat list to mute/unmute the radio beep (crossed speaker in the header). No beep and no vibration during Quiet Time. Optional phone notifications when the app is closed via ntfy, Telegram or Pushover (set up in the settings).
