Was dieser Server macht

  • Er vermittelt Nachrichten zwischen Pebble-Uhren: Kontakt auf der Uhr wählen, sprechen – der Text kommt auf der Uhr des anderen an.
  • Nachrichten werden auf dem Handy verschlüsselt (NaCl). Der Server speichert nur Chiffretext und kann sie weder lesen noch fälschen.
  • Er kennt Benutzernamen, Kontakte, Gruppen und höchstens die letzten 50 Nachrichten je Chat für 30 Tage – sonst nichts. Keine E-Mail, keine Telefonnummer, kein Tracking.
  • Akkuschonend: Bei offener App fragt das Handy einmal und der Server antwortet, sobald etwas Neues da ist (Long-Polling). Ist die App zu, meldet auf Wunsch eine Handy-Benachrichtigung über ntfy, wer geschrieben hat.

Eigenen Server betreiben

Alles ist Open Source (MIT). Der Server ist eine einzige Node.js-Datei ohne Abhängigkeiten und ohne Datenbank – betreib ihn für deine Freunde:

Node.js ≥ 18

git clone https://github.com/sgitaize/Pebble-WatchieTalkie
cd Pebble-WatchieTalkie/server
PORT=3000 node server.js

Docker

cd Pebble-WatchieTalkie/server
docker compose up -d        # Port 3000, Daten im Volume "data"

Webhosting (Plesk)

Server-Ordner hochladen, Node.js aktivieren mit Anwendungsstamm = Ordner, Startdatei server.js. HTTPS davor (Let's Encrypt, Caddy, nginx). Mit REGISTER_CODE bleibt der Server privat.
